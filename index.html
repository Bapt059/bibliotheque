Comment obtenir un token GitHub ?
  1. Va sur github.com/settings/tokens
  2. "Generate new token (classic)"
  3. Coche uniquement le scope gist
  4. Choisis une expiration longue (1 an ou "No expiration")
  5. Copie le token (ghp_...) et colle-le ci-dessous
